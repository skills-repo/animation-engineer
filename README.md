# Animation Engineer — 动画工程师技能库

> 面向独立开发者和前端开发者的动画与动效技能集合。覆盖动效原理、CSS 动画、移动端交互和 React 声明式动画，帮你为产品注入专业级动效体验。

## 技能清单

| 技能 | 描述 | 安装量 | 来源 |
|------|------|--------|------|
| animation-vocabulary | 动效词汇与动画原则：缓动曲线、时长规范、编排策略、响应式动效 | 55.7K | [skills.sh](https://skills.sh/emilkowalski/skills/animation-vocabulary) |
| tailwind-animations | Tailwind CSS 动画工具集：内置动画类、自定义关键帧、过渡效果 | 2.2K | [skills.sh](https://skills.sh/josiahsiegel/claude-plugin-marketplace/tailwindcss-animations) |
| mobile-touch | 移动端触控交互动效：手势动画、触控反馈、页面过渡、物理质感 | 2.1K | [skills.sh](https://skills.sh/dylantarre/animation-principles/mobile-touch) |
| framer-motion | React 声明式动画：布局动画、手势系统、SVG 动画、编排与变体 | 2.1K | [skills.sh](https://skills.sh/mindrally/skills/framer-motion) |

## 工作流

```
动效词汇 ──→ Tailwind 动画 / Framer Motion
 (设计原则)     (CSS 实现 / React 实现)
     └──→ 移动端触控
          (手势交互)
```

## 安装

```bash
# 安装全部动画技能
npx skills add skills-repo/animation-engineer

# 或按需安装单个技能
npx skills add skills-repo/animation-engineer@animation-vocabulary
npx skills add skills-repo/animation-engineer@tailwind-animations
npx skills add skills-repo/animation-engineer@mobile-touch
npx skills add skills-repo/animation-engineer@framer-motion
```

## 与本组织其他仓库的关系

- **design-studio** — UI/UX 设计（设计系统、UI审查），本仓库聚焦动效与动画实现
- **frontend-engineer** — 前端组件开发、性能优化，本仓库聚焦交互动画层面
- **indie-game-developer** — 游戏开发（Three.js），本仓库聚焦 Web/移动端 UI 动效
